# 🧮 Calculator

Aplicación web interactiva de una calculadora moderna y responsiva construida con estándares web fundamentales (HTML5 y CSS3).

---

## 🚀 Características

- **Diseño Responsivo:** Interfaz adaptada para visualizarse correctamente en pantallas de escritorio y dispositivos móviles.
- **Estilos Personalizados:** Diseño estilizado con CSS3[cite: 5].
- **Estructura Semántica:** Construcción limpia en HTML5[cite: 5].

---

## 📁 Estructura del Proyecto

```text
Calculator/
├── index.html    # Estructura principal y maquetación de la calculadora
├── style.css     # Estilos visuales, layout y diseño responsivo
└── README.md     # Documentación del proyecto
```[cite: 5]

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Marcado de la interfaz y botones[cite: 5].
- **CSS3:** Estilos, colores y disposición de la interfaz[cite: 5].
